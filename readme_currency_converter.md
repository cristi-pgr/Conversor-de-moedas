## 👁️ Overview & Live Demo

The **Currency Converter** provides a user-friendly interface for seamless conversion between global currencies (such as Brazilian Real and US Dollar). Built with a minimalist and responsive design, it provides visual indicators for the selected currencies.

## 🛠️ Technologies Used

This project was developed using the following tools and technologies:

- [**HTML5**](https://developer.mozilla.org/en-US/docs/Web/HTML): Markup structure for user interface components.
- [**CSS3**](https://developer.mozilla.org/en-US/docs/Web/CSS): Modern layout styling, responsive design, and component alignment.
- [**JavaScript (ES6+)**](https://developer.mozilla.org/en-US/docs/Web/JavaScript): DOM manipulation, conversion logic, and dynamic flag updating.

## 🚀 Getting Started

### Prerequisites

To run this application locally, you only need a modern web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/your-repository-name.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd your-repository-name
   ```

3. **Open the project:**
   - Double-click the `index.html` file to open it in your default web browser.
   - Alternatively, open the directory in **VS Code** and run it using the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.

## 📌 Features & Roadmap

### Current Features

- [x] Dynamic selection for origin currency (*Convert from*).
- [x] Dynamic selection for target currency (*To*).
- [x] Formatted currency value input field.
- [x] Visual representation displaying current currency flags and symbols.
- [x] Instant conversion calculation triggered on button click.

### Planned Improvements (Roadmap)

- [ ] Integration with a live Exchange Rate API (e.g., *ExchangeRatesAPI* or *AwesomeAPI*).
- [ ] Quick-swap button to reverse target and source currencies.
- [ ] Support for additional global currencies (Euro, British Pound, Japanese Yen, etc.).
- [ ] Conversion history log.
- [ ] Dark Mode / Light Mode theme toggle.
